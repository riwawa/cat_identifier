# Identifying my cats

https://github.com/user-attachments/assets/5c1a3c82-fcef-4a6d-a039-c149508b6d69

Computer vision mini-project, built as a stepping stone toward a home robot project. Goal: given an image or video, detect a cat and identify which cat it is (Rodolfo or Luna) — not just "there's a cat here."

## Pipeline

```
Image/frame
     ↓
[1] DETECTION (pretrained YOLOv8n, "cat" class from COCO)
     ↓
[2] CROP the cat region
     ↓
[3] IDENTIFICATION — two approaches implemented and compared:
     a) Classification via transfer learning (ResNet18 + trained final layer)
     b) Embedding similarity (frozen ResNet18 + cosine-similarity comparison
        against reference prototypes for each cat)
```

## File structure

| File | What it does |
|---|---|
| `detectar_gato.py` | First isolated detection test (single photo) |
| `classificacao_gato.py` | Main script: loads the dataset, trains the classifier, computes the embedding prototypes, evaluates both methods, saves the artifacts |
| `diagnostico_pixels_escuros.py` | Measures the proportion of dark pixels per class — used to investigate a bias found in the model (see "Known limitations") |
| `webcam_ao_vivo.py` | Runs the full pipeline (detection + classification) in real time, using the webcam |
| `dataset/` | Training/validation photos, organized as `dataset/luna/` and `dataset/rodolfo/` (folder structure = label, read automatically by `ImageFolder`) |
| `modelo_classificador.pth` | Trained weights of the classifier's final layer (generated by running `classificacao_gato.py`) |
| `prototypes.pth` | Reference vectors (prototypes) for each cat, used by the embedding approach |
| `classes.pth` | List of class names, in the order used by the model (avoids hardcoding it elsewhere) |

## How to run

**1. Environment setup:**
```bash
python3 -m venv venv
source venv/bin/activate
pip install ultralytics opencv-python torch torchvision
```

**2. Train (or retrain) the classifier:**
```bash
python classificacao_gato.py
```
This loads the dataset, trains the final layer (10 epochs), computes the embedding prototypes, evaluates both methods on the validation set, and saves `modelo_classificador.pth`, `prototypes.pth`, and `classes.pth`.

**3. Test live on webcam:**
```bash
python webcam_ao_vivo.py
```
Opens the webcam, detects and identifies cats in real time. Press `q` to quit.

## Results

Validation accuracy across dataset iterations (varying with dataset size/balance each round):
- Classification (transfer learning): ~93–96%
- Embeddings (cosine similarity, no fine-tuning): comparable results, sometimes converging on the same errors as classification
